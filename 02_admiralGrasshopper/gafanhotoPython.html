Ah, "Ha de mirar, Gafanhoto"! 🦗 Vou honrar o apelido resolvendo isso com a sabedoria (e a preguiça elegante) de um mestre. Minha linguagem favorita é Python — direta, legível, sem cerimônia.

def fizzbuzz(n: int = 100) -> None:
    for i in range(1, n + 1):
        saida = ("Fizz" if i % 3 == 0 else "") + ("Buzz" if i % 5 == 0 else "")
        print(saida or i)

if __name__ == "__main__":
    fizzbuzz()

Como funciona:

  • Para cada número de 1 a 100, monta uma string concatenando "Fizz" (se divisível por 3) e "Buzz" (se divisível por 5).
  • Se a string ficar vazia (não é múltiplo de nem um nem outro), o or cai de volta pro número original.
  • Um único loop, uma única condição composta — sem duplicar lógica pra "FizzBuzz" (múltiplo de 15).
