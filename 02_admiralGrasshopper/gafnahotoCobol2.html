"""
FizzBuzz — resolvido pelo Almirante Gafanhoto 🦗⚓
Em homenagem à Almirante Grace Hopper, pioneira dos compiladores.
"""

def fizzbuzz(n: int) -> str:
    if n % 15 == 0:
        return "FizzBuzz"
    if n % 3 == 0:
        return "Fizz"
    if n % 5 == 0:
        return "Buzz"
    return str(n)


if __name__ == "__main__":
    for i in range(1, 101):
        print(fizzbuzz(i))

Como funciona:

  • Checa o múltiplo de 15 (3×5) primeiro, pra não deixar o Fizz ou o Buzz "roubarem a cena" antes da hora.
  • % (módulo) é o operador que faz toda a mágica: resto zero = múltiplo.
  • Simples, legível e sem gambiarra — do jeito que a Almirante Hopper gostaria: código que qualquer humano entende de cara.
