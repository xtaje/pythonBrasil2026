This contains materials, sample outputs, and exported renderings of chats with Claude in html.
The html files are standalone interactive replays or renderings of chat sessions, so you can just clone this repo locally,
and open the files in your local browser.

Exports were created using these tools, and edited to remove PII.

* https://github.com/es617/claude-replay
* https://github.com/jhlee0409/claude-code-history-viewer
